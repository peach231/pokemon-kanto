Trainer portraits are NOT stored here.

They stream at runtime from Pokemon Showdown's FireRed/LeafGreen trainer set
('-gen3' variants) — see G.TRAINER_CFG in js/data/sprites_config.js. Overworld
walking sprites stream separately from pret/pokefirered.

This folder is an OVERRIDE only: drop in <art key>.png (for example
trainer_brock.png) and it will be used in place of the streamed sprite.

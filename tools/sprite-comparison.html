Overworld sprites: streamed or hand-authored?

Four characters, both ways. Left of each pair is the real FireRed sprite the game streams today; right is the same character hand-drawn in the engine’s native 16×24 palette format. Both are sliced and bottom-anchored by identical code, so neither side is flattered by framing.

Recommendation: keep streaming

The streamed set is better pixel art and it isn’t close. Every surface has a lit side and a shadow side; mine are flat fills with an outline round them. Set the zoom to 1× above — that is the size these actually appear in game — and the streamed faces still read while mine mostly collapse.

The one honest argument for hand-authoring is palette coherence: my samples draw from the same master palette as the tileset, so they would sit in the world by construction. But the streamed sprites already look right on the Kanto tiles in-game, so that advantage stays theoretical while the quality gap does not.

Streaming is also already wired and complete — pokefirered covers the entire Kanto cast, so nothing renders as a placeholder. Choosing it costs nothing; choosing hand-drawn costs a full cast at this quality bar or worse.
